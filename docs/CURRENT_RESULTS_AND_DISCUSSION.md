# Current Results and Discussion

## Current Result

The completed deterministic Python re-analysis examined whether the timing pattern differed when an outcome was linked to behavior rather than delivered on a matched schedule. The planned contingent-minus-yoked contrast was negative in most matched pairs. It kept that direction when the summary was recalculated with one matched pair left out at a time. These observations are the limited supportive part of the current result.

The component-selection check also found that, within each model fit, the selected component had the intended positive association with retraction under the stated selection rule. This supports the internal use of that rule within a fit. It does not show that components fitted separately represent the same pattern.

Important non-supportive findings qualify the directional pattern. The timing contrast was not precise or stable across the planned checks that varied component complexity and smoothing. The descriptive comparison with an archived reference showed broad directional correspondence at one level but incomplete agreement for individual matched pairs, and the methods were not identical. Taken together, the current result is **directionally suggestive but inconclusive**.

## Interpretation

In plain language, the completed analysis provides a hint about the direction of the timing difference under one fixed computational route. A hint is useful for framing a later question, but it is not enough to settle that question. The result depends on a set of analysis choices, and the planned checks showed that the estimated timing difference did not remain dependable across those choices.

The component-selection result is a check on how the analysis rule behaved, not evidence that the selected patterns have a fixed biological identity. Likewise, the descriptive comparison is a limited quality-control observation, not confirmation that two analysis approaches give the same answer.

## What the Result Does Not Show

This result does not establish that a timing difference is robust, precise, or reproducible under reasonable analysis choices. It does not identify a preferred complexity or smoothing setting, and it does not justify choosing a setting after seeing which one gives a favorable direction.

It does not establish a causal explanation, a biological mechanism, or that a statistical component maps to a particular cell type or circuit process. It also does not provide an exact rerun, numerical replication, or method-equivalence claim. The exact reference MATLAB/seqNMF workflow was not run. Alternative estimators were not used to support the research conclusion.

## Discussion and Future Testing

Future work can ask prospective, testable questions rather than treating the present pattern as an answer. Under analysis choices specified before outcomes are examined, does the matched timing contrast retain its direction and become sufficiently stable to support a clearer conclusion? Do justified changes in component complexity and smoothing lead to consistent interpretations? If an appropriate, approved data boundary is in place, does an independently documented execution of the reference MATLAB/seqNMF workflow lead to a compatible qualitative finding? Can independently fitted components be matched by a rule specified in advance rather than assumed to be identical?

Any such evaluation should protect against selective interpretation. The question, eligible data, preprocessing, matching rule, component-selection rule, model settings, uncertainty assessment, and decision criteria should be specified before outcome review. The plan should report all planned checks, including non-supportive results, and should not promote one setting solely because it appears favorable after inspection. Maintainers should confirm data rights and the release boundary before research-facing work begins. Research material and result-bearing outputs should remain outside this data-free public tree unless the boundary is explicitly reviewed and changed.
